# Task 3 Plan: Inventory Source Refactor

## Summary

Replace the aggregate pollution-source loading path with a named inventory loader. Preserve each proxy category independently because raw scales are not comparable, normalize each cropped source explicitly, and expose aligned source maps and matrix metadata for later IASA activity modeling.

## Implementation Changes

- Add `sim/pol_sources.py` with a `PolSourceInventory` dataclass.
- Load seven source maps in stable order: brick kilns, industries, population density, and traffic at 00, 06, 12, and 18 hours.
- Preserve crop `(21:61, 16:56)`, yielding `[7, 40, 40]` maps.
- Normalize each cropped source by its own 99th percentile and record the scale per source.
- Handle an all-zero source by returning a zero map, using a safe scale, and recording it in metadata.
- Return source names, source maps, flattened source matrix `[1600, 7]`, activity defaults, source files, crop, raw statistics, normalization convention, and zero-source metadata.
- Integrate inventory loading into `sim/polsim.make_grid(load_inventory=True)` without constructing an aggregate source.
- Remove the legacy aggregate source loader and all default aggregate-loading behavior.

## Tests

- Verify source order, shapes, crop metadata, files, and normalization metadata.
- Verify each nonzero map has cropped p99 near one.
- Verify the zero traffic source remains zero and is reported explicitly.
- Verify grid inventory loading is opt-in and never creates an aggregate source field.
- Run source tests and the IASA runtime smoke script in Singularity.

## Assumptions

- Named source maps remain independent through Task 3.
- Activity factors are introduced in Task 4.
- No residual or unknown free spatial field is part of the new path.
