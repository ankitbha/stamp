# Task 4 Plan: Inventory Activities And Wind Providers

## Summary

Create the first reusable IASA activity and wind layer. Turn named source maps into nonnegative time-varying source terms, support low-dimensional temporal bases, and expose real New Delhi plus controlled synthetic wind sequences.

## Activity API

- Add `model/iasa/activity.py` with `ActivityProfile`, `TemporalBasis`, validation helpers, and `combine_inventory_sources`.
- Add a default activity builder returning `theta[T,K]` and explicit proxy metadata.
- Add a basis-coefficient API mapping basis `[T,B]` and coefficients `[K,B]` to `theta[T,K]`.
- Traffic uses nearest 00/06/12/18 time slices.
- Brick kilns use a deterministic seeded blocky/intermittent proxy.
- Industry uses a day-heavy profile mixed with an `industry_24h_fraction`; spatial sampling remains metadata-only in v1.
- Population density uses a baseline with morning, afternoon, and evening cooking peaks.
- Validate finite, aligned, nonnegative source maps and activities.

## Wind API

- Add `model/iasa/wind.py` with `WindSequence`.
- Load city-level `Vx/Vy` from the saved Task 2 imputed wind product for provider `real_imputed_new_delhi`.
- Permit observed-only fallback only when explicitly requested and label it `real_observed_new_delhi`.
- Add deterministic providers for constant, single-direction, diurnal, AR(1), and multi-direction synthetic wind.
- Preserve timestamps, provider name, seed/config, and exact wind arrays.

## Integration And Tests

- Update the minimal sanity runner to use shared activity and wind primitives.
- Test zero and one-hot source combination, negative validation, traffic slots, daytime industry behavior, population cooking peaks, and one-basis coefficients.
- Test imputed-product loading, explicit observed fallback, provider shapes, metadata, and seeded reproducibility.
- Run the full source/weather/activity/wind tests, sanity runner, and runtime smoke in Singularity.

## Assumptions

- Task 4 does not implement response matrices, projection, diagnostics, fitting, or merging.
- Industry spatial splitting is deferred.
- Activity defaults are proxy priors, not calibrated emissions truth.
