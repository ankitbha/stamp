# Task 5 Plan: Open-Boundary Gaussian Puff Response Matrix

## Summary

Implement `H_lag` construction in `model/iasa/response.py` as the paper-facing IASA response builder. The model is an open-boundary Gaussian puff approximation: puffs advect through wind, spread with anisotropic Gaussian covariance, lose mass outside the physical domain, and never wrap, reflect, clamp, or renormalize boundary loss. Extend the sanity runner with Gate S1 response checks using synthetic impulse releases.

- Add `build_lagged_response_matrix(source_maps, source_names, activity_basis, observer, wind_sampler_or_sequence, response_config=None, dispersion_config=None) -> ResponseMatrixResult`.
- Input shapes:
  - `source_maps`: `[K, Nx, Ny]`, nonnegative;
  - `activity_basis`: `[T, B]`, with source-major `(source, basis)` output columns;
  - default output: `H_lag.shape == [M * T, K * B]`;
  - with `trim_initial_lag=True`, rows begin after `lag_window_steps - 1` and metadata records `T_effective`.

## Key Implementation Changes

- Use grid-index coordinates. Cell centers are integer points and physical open extents are `[-0.5, Nx - 0.5] x [-0.5, Ny - 0.5]`. A puff exits when its center leaves those extents.
- Initialize each release at its source cell center and advect it to observation time using substeps. Use a fractional final substep so the puff lands exactly at the observation time.
- Include same-time rows where `t == tau`. Define `age = (t - tau) * dt` and `effective_age = max(age, min_dispersion_time)` so zero-age releases have a finite Gaussian kernel.
- Use covariance eigenvalues `sigma_parallel^2 * effective_age` and `sigma_perp^2 * effective_age`, rotating the parallel axis along the mean downwind trajectory. Use `zero_wind_orientation` near zero wind.
- Record retained and dropped mass per release kernel or `(source, basis, tau, t)`. Do not infer physical mass by summing `H_lag` rows. Track exit loss separately by release event and aggregate by column.
- Metadata must include `boundary_mode="open"`, `response_implementation="open_boundary_gaussian_puff"`, response and dispersion configs, exact city wind arrays when available, wind metadata, row and column indices, source and basis names, baseline policy/vector, retained/dropped summaries, exit counts, exit-time summaries, and exited release mass by column.
- Task 5 v1 uses `baseline_policy="zero_source"`; return and subtract an all-zero row-aligned baseline through the same pathway reserved for later background handling.
