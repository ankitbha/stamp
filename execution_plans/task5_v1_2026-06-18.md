# Task 5 Plan v1: Open-Boundary Gaussian Puff Response Matrix

## Summary

Implement `H_lag` in `model/iasa/response.py` using an open-boundary anisotropic Gaussian puff approximation rather than the edge-hold PDE simulator. Build sensor-time fingerprints for every source/basis column and add Gate S1 synthetic response checks.

## Initial Public Contract

- Add response, dispersion, observer, and result dataclasses.
- Add `build_lagged_response_matrix(source_maps, source_names, activity_basis, observer, wind_sequence, response_config, dispersion_config)`.
- Accept source maps `[K,Nx,Ny]`, temporal bases `[T,B]`, sensors `[M,2]`, and city wind arrays `[T]`.
- Return `H_lag[M*T,K*B]`, row/column mappings, baseline, and metadata.

## Transport And Dispersion

- Release puffs from weighted source cells at each basis release time.
- Advect with configurable substeps and remove puffs after domain exit.
- Evaluate anisotropic Gaussian sensor response aligned to mean wind direction.
- Use separate parallel and perpendicular dispersion parameters and a minimum dispersion time.
- Drop mass outside the domain or truncated support without renormalization.
- Record boundary mode, response implementation, wind, dispersion, retained/dropped mass, and exit summaries.

## Initial Gate S1

- Use a synthetic `16x16` grid, 40-80 times, lag 8-16, three sources, four sensors, and deterministic wind.
- Check matrix shape/nonzero response, downwind arrival, edge exit, no wraparound, boundary loss, anisotropic-vs-isotropic response, and deterministic reruns.
- Extend the sanity runner with response and future gate options.

## Tests

- Cover shape/metadata, zero response, one-hot columns, exit/no-wrap behavior, boundary loss, anisotropy, reproducibility, and invalid inputs.
