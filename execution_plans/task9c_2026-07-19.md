## Objective

Add the optional refinement stage that jointly corrects wind (`phi`), dispersion
(`psi`), source coefficients (`c >= 0`), and background coefficients (`gamma`)
*only within physical limits and only when identifiability is preserved*. The
fixed-response IASA solution stays the default reported estimate; refinement is a
constrained local correction reported with its own diagnostics.

## Design

### Reduction of the objective (why the inner solve is `fit_projection`)

The paper objective is
```
L_refine = ||Y - H_lag(phi,psi) c - Q gamma||^2 + lambda_theta R(c)
         + lambda_w ||w_phi - w_phi0||^2 + lambda_psi ||psi - psi0||^2
         + lambda_sm R_sm(w_phi)
```
For fixed `(phi, psi, c)`, `min_gamma ||Y - H_lag c - Q gamma||^2 =
||Y_tilde - H_tilde c||^2` (orthogonal projection onto `range(Q)^perp`, the exact
identity Task 6 already uses). So the `gamma` block is eliminated by re-projecting
against the **same** background basis and the inner `(c, gamma)` solve for fixed
`(phi, psi)` is exactly `fit_projection` (projected FISTA, `c >= 0`, ridge
`R(c)=||c-c0||^2` via `FitConfig.lambda_reg=lambda_theta`). Its
`objective_summary["final"]` equals `||Y_tilde - H_tilde c||^2 + lambda_theta R(c)`
— the first two terms of `L_refine`. The remaining three terms depend only on
`(phi, psi)`. Hence `L_refine` is a **low-dimensional** function of `(phi, psi)`:
each evaluation = rebuild `H_lag`, re-project, `fit_projection`, add penalties.

### Wind parameterization `phi`

A smooth, low-dimensional additive correction to the base transport field:
`w_phi(t) = w0(t) + Phi_corr[t] @ A`, where `Phi_corr` is a predeclared correction
temporal basis `[T, P]` (default: constant + linear, `P=2`) and `A` is `[P, 2]`
(the `(Ux, Vy)` components). This keeps corrections smooth (few DOF) and makes the
constraints tractable:
- `||w_phi - w_phi0||_2^2 = ||delta||^2` with `delta[t] = Phi_corr[t] @ A`
  (base cancels).
- `||w_phi - w_phi0||_inf = max_t max_component |delta[t]|` (the `eps_w` box).
- `R_sm(w_phi) = sum_t ||w_phi[t+1] - w_phi[t]||^2` on the corrected integer-time
  field (paper writes `R_sm(w_phi)`; equals `R_sm(delta)` up to the fixed base and
  coincides exactly when the base is constant).

Applied through a `_CorrectedWindSampler` that wraps the base `WindSampler`
(`WindSequence` -> `CityWindSampler`) and adds the `t`-interpolated correction to
`sample(t, position)`. Position-independent additive shift, so the field
difference is exactly `delta` regardless of sensor/grid geometry.

`eps_w` feasibility is enforced by scaling `A` (delta is linear in `A`):
`A <- A * min(1, eps_w / max_inf(delta))`.

### Dispersion parameterization `psi`

`psi = (sigma_parallel, sigma_perp, min_dispersion_time)`, clamped to the physical
box `Psi_phys = [psi_lower, psi_upper]` (all strictly positive; the Task 5 builder
already rejects non-positive dispersion).

### Outer optimizer (deterministic, derivative-free)

The Task 5 builder (advection + Gaussian pullback) is not a clean autograd target,
so I use a deterministic **coordinate pattern search** (Hooke–Jeeves-style, no RNG)
over the free params `[vec(A) (if refine_wind), psi (if refine_dispersion)]`:
- start at `A=0, psi=psi0` (=> `L_refine(0,psi0)` = fixed-response objective +
  `lambda_sm R_sm(w0)`),
- per coordinate try `+step`/`-step`, project to feasibility (`eps_w` scale, `psi`
  clamp), accept the best strictly-improving move,
- shrink `step *= shrink` when a sweep yields no improvement; stop at
  `max_outer_iters` or `step < tol_step`.
Fully deterministic (seed-free), so gate output is reproducible.

### Acceptance (paper eqs. refinement_smin_check / refinement_coherence_check)

Rebuild diagnostics on the refined projected `H_tilde_ref`:
- `sigma_J_eff = sigma_J if numerical_rank == J else 0.0` (paper: fewer than `J`
  numerically nonzero singular values => `sigma_J` taken as 0; cannot accept by
  exploiting rank deficiency). Applied to **both** baseline and refined.
- `rho_ref = max over eligible pairs (i != j, i,j not in W)` of coherence
  (nan-max over off-diagonal of `diagnostics.coherence`, which is already NaN for
  weak/ineligible entries).
- `accepted = (sigma_J_ref_eff >= (1 - eta_id) * sigma_J_0_eff) and
  (rho_ref <= tau_rho_ref)`.
Regardless of acceptance, the fixed-response fit remains the default report
(`RefineResult.fixed_response_fit`), and the refined solution is reported with its
own diagnostics.

## Acceptance checks (tests + gate)

1. **Local-correction feasibility**: refined `delta` satisfies
   `||delta||_inf <= eps_w + tol` and refined `psi` in `Psi_phys` (both bounds).
2. **Fit-improvement path**: on a scenario whose data were generated with a wind
   slightly off the declared base, refinement lowers the projected data residual
   (`objective_data_end <= objective_data_start`), stays feasible, and is accepted.
3. **Rejection on separability loss**: a config that would drive coherence up /
   `sigma_J` down (e.g. `eta_id=0`, `tau_rho_ref` set below the achieved coherence,
   or a synthetic where refinement collapses rank) is **rejected**; assert the
   rank-deficiency rule sets `sigma_J_eff=0`.
4. **Default preserved**: `RefineResult.fixed_response_fit.c_hat` equals the
   input fixed-response fit exactly (no mutation), independent of acceptance.
5. **Determinism**: two runs give identical `A`, `psi`, objective breakdown.
6. **No-op safety**: with `lambda_w`/`lambda_psi` large (strong anchor), optimizer
   stays at the base (A~0, psi~psi0) and `accepted=True` (sigma_J unchanged).
7. Public exports present.
