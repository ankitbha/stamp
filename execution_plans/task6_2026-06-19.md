# Task 6 Implementation Plan: Low-Dimensional Background Projection

## Summary
Implement the paper’s background model and Moore-Penrose projection as new IASA primitives. Background columns must follow Task 5’s time-major row ordering, remain source-independent and low-rank in normal operation, and expose the effective projection subspace and removed components needed by Task 7. Extend the sanity runner with Gate S2 using the existing eight-column Task 5 response.

## Public APIs
- Add `model/iasa/background.py`:
  - `BackgroundBasisConfig`: constant flag, temporal polynomial degree, daily harmonic count, day intercepts, regional coordinate trends, sensor offsets, `max_background_rank=8`, and basis mode (`normal` or `stress`).
  - `BackgroundBasisResult`: `Q`, column names, row index, and JSON-safe metadata.
  - `build_background_basis(row_index, timestamps, sensor_xy=None, config=None, user_basis=None, user_basis_names=None)`.
- Add `model/iasa/projection.py`:
  - `ProjectionConfig(rank_tolerance=None, allow_over_rank=False)`.
  - `BackgroundProjector`: `Q`, effective orthonormal basis `U_r`, singular values, effective rank, tolerance, row index, column names, and metadata; expose `project(X)`.
  - `ProjectionResult`: `H_tilde`, `Y_tilde`, `H_removed`, `Y_removed`, `Q`, `U_r`, row/column indices, and metadata.
  - `fit_background_projector(background_basis, config=None)`.
  - `project_response_and_observations(H_lag, Y, background_basis, row_index, column_index, config=None)`.
- Export these public types and functions from `model.iasa`.
- Perform projection algebra in `float64`; preserve Task 5 arrays and metadata without mutation.

## Implementation Steps
1. **Build row-aligned background columns**
   - Treat Task 5 `row_index` as authoritative. Validate contiguous time-major ordering, sensor IDs/indices, and that every time has the same sensor ordering.
   - Require `timestamps` to cover every referenced `time_index`; map each stacked row to its timestamp.
   - Construct columns deterministically:
     - constant: all ones;
     - temporal polynomial: centered/scaled time powers through the requested degree;
     - daily harmonics: `sin(2πht/24)` and `cos(2πht/24)` for each requested harmonic;
     - day intercepts: reference-code days by dropping the first level;
     - regional trends: standardized sensor `x` and `y`, repeated over time;
     - sensor offsets: reference-code sensors by dropping the first sensor.
   - Validate user basis shape `[mT, r_user]`, finiteness, unique names, and identical row ordering.
   - Record column provenance, requested column count, sensor/time counts, centering/scaling, rank cap, and whether the basis is normal or a labeled stress basis.

2. **Enforce low-dimensional normal backgrounds**
   - Normal constructors may use only timestamps, day labels, sensor IDs, and sensor coordinates; their API must not accept `H_lag` or source maps.
   - Reject a normal basis whose effective rank exceeds `max_background_rank=8`.
   - Keep source-like columns outside the production constructor. Gate S2 may create them only through a private stress-test helper labeled `basis_mode="stress"`.
   - Empty configurations return `Q` with shape `[mT, 0]`.

3. **Fit the projection subspace**
   - Compute thin SVD `Q = UΣVᵀ`.
   - Default tolerance: `max(Q.shape) * eps(float64) * sigma_max`; honor an explicit nonnegative override.
   - Set `U_r` to singular vectors above tolerance. For empty `Q`, return `[mT, 0]`, rank zero, and tolerance zero.
   - Identify independent/dependent input columns deterministically by left-to-right rank increase using the same tolerance; record both name lists.
   - Reject over-rank normal bases unless `allow_over_rank=True` and the basis is explicitly labeled as stress.
   - Implement projection as `X - U_r @ (U_r.T @ X)` without materializing an `mT × mT` projector.

4. **Project observations and responses**
   - Validate `H_lag.shape[0] == Y.shape[0] == Q.shape[0] == len(row_index)` and exact equality between response and basis row metadata.
   - Accept `Y` only as `[mT]`; accept `H_lag` as `[mT, K_basis]`.
   - Produce `H_tilde`, `Y_tilde`, `H_removed`, and `Y_removed` using the same fitted projector.
   - Preserve Task 5 `column_index`.
   - Record input/output shapes, method, rank, singular values, tolerance, basis names/types, row ordering, orthogonality residuals, idempotence residual, and per-column projected/removed norm ratios.
   - Keep `Q` and `U_r` as result arrays; keep metadata JSON-safe.

5. **Integrate Gate S2**
   - Refactor the Task 5 toy construction into a reusable helper returning its `ResponseMatrixResult`, wind timestamps, observer, and basis. Preserve Gate S1 behavior and output.
   - Add `run_projection_gate()` and route `--gate projection` to it.
   - Update `--gate all` to run Task 3A, response, and projection; only diagnostics, fit, and merge remain skipped.
   - Assert the Task 5 column order is exactly:
     - west impulse, west constant;
     - east-edge impulse, east-edge constant;
     - south impulse, south constant;
     - interior impulse, interior constant.
   - Use:
     - `c_true = [1.0, 0.5, 0.0, 0.25, 0.75, 0.0, 0.4, 0.2]`;
     - normal rank-four `Q`: constant, centered linear trend, first daily sine, first daily cosine;
     - `beta = [0.3, -0.1, 0.2, 0.15]`;
     - `Y = H_lag @ c_true + Q @ beta`.
   - Verify empty-basis no-op, exact background removal, orthogonality, idempotence, row alignment, rank-four metadata, and reconstruction from saved `U_r`.
   - Add a redundant basis by duplicating the constant column; require effective rank four and projections identical to the independent basis.
   - Add a normalized `interior_source/constant` response column to a labeled stress basis; require lower visibility and higher absorption for that column.
   - Enforce:
     - orthogonality residuals at `1e-6` relative tolerance;
     - idempotence residual at `1e-8`;
     - normal visibility ratio at least `0.8`;
     - normal absorption ratio at most `0.6`;
     - stress visibility below normal and stress absorption above normal.
   - Include coefficients, column mapping, ranks, residuals, visibility, absorption, and stress labels in Gate S2 JSON output.

6. **Update tests**
   - Add `tests/test_iasa_background.py` for all constructors, exact time-major values, reference coding, regional trends, user basis, empty basis, rank cap, and validation failures.
   - Add `tests/test_iasa_projection.py` for empty/constant projection, redundant columns, tolerance handling, idempotence, reconstruction, row-order mismatch, shape/nonfinite errors, over-rank rejection, result metadata, and JSON serialization.
   - Add a command-level projection-gate test or directly test `run_projection_gate()` on the shared toy.
   - Update package-export tests for all new public symbols.
   - Keep every existing Task 3A–5 test unchanged and passing.
