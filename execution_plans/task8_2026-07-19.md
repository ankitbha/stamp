# Task 8 Execution Plan: IASA nonnegative fitting

## Objective

Estimate nonnegative source--basis coefficients for the projected inverse
problem

```text
c_hat = argmin_{c >= 0} ||Y_tilde - H_tilde c||^2 + lambda R(c),
R(c) = ||c - c0||^2   (ridge when c0 = 0)
```

with **projected FISTA as the sole solver path** (PyTorch, input device, inverse
dtype float64; no SciPy, no CPU transfer for fitting). Reconstruct source
activity `theta_k(t) = sum_b c_kb phi_b(t)`, aggregate interpretable
apportionment summaries, estimate active-set covariance, and provide a
calibrated refitted parametric-bootstrap residual model-adequacy check that
degrades safely to `uncalibrated` when no external noise contract exists.

## Context (verified)

- Task 6 `ProjectionResult` provides torch tensors `H_tilde`, `H_removed`,
  `Y_tilde`, `Y_removed`, `Q`, `U_r`, plus `row_index`, `column_index`
  (source-major/basis-minor: `source_index, source_name, basis_index,
  basis_name`) and device/dtype provenance. `H_lag = H_tilde + H_removed`,
  `Y = Y_tilde + Y_removed`. `U_r` is an orthonormal basis of the background

## Design -- new `model/iasa/fit.py`

### Config
`FitConfig(lambda_reg=0.0, prior_mean=None, fixed_zero_indices=(),
max_iters=10000, tol_kkt=1e-6, tol_rel_obj=1e-12, active_tolerance=1e-8,
tau_sigma=None, device=None, dtype="float64", ensemble_kind="transport",
lipschitz_sigma1=None, use_power_iteration=False, power_iters=100,
condition_warning_ratio=1e8, seed=0)`.

### Projected FISTA (sole solver), batched
`_projected_fista(H, Y, prior, lam, *, sigma1, step, max_iters, tol_kkt,
tol_rel_obj)`; `Y` may be `[N]` or `[N,B]` (bootstrap/ensemble batch), `c` is
`[J]`/`[J,B]`.
- Gradient `g(c) = 2 H^T(H c - Y) + 2 lam (c - prior)`; proximal step for the
  nonnegativity indicator is `clamp(., min=0)`.
- Lipschitz `L = 2 (sigma_1^2 + lam)`, `step = 1/L`; `sigma_1` from
  `torch.linalg.svdvals(H)[0]` by default, or a recorded power-iteration
  estimate (`use_power_iteration`), or an explicit override. Record method.
- **Monotone restart:** when the accelerated candidate raises the objective
  (per column), take the plain projected-gradient step from the current iterate
  and reset momentum `t=1` for those columns; else FISTA momentum
  `t_{k+1}=(1+sqrt(1+4 t_k^2))/2`, `y = c_new + ((t_k-1)/t_{k+1})(c_new - c)`.
- **Stop** when both the reduced-gradient/KKT residual
  `kkt_j = g_j if c_j>0 else min(g_j,0)` (L2 norm, per column) `<= tol_kkt`
  **and** relative objective change `<= tol_rel_obj`, or `max_iters` reached.
  Report `convergence_status`, `iteration_count`, `restart_count`, `kkt_residual`.

### Core entry points
- `fit_sources(H_tilde, Y_tilde, column_index, *, config=None,
  temporal_basis=None, timestamps=None, H_lag=None, U_r=None, Y=None,
  diagnostics=None) -> FitResult`.
- `fit_projection(projection_result, *, config=None, temporal_basis=None,
  timestamps=None, diagnostics=None)` pulls `H_tilde, Y_tilde, H_lag, U_r,
  Y=Y_tilde+Y_removed, column_index` from a `ProjectionResult`.

Steps (torch on device/dtype):
1. Validate/resolve; build `fixed_zero_indices` reduction
   (`reduced_to_original`, `original_to_reduced`) exactly as Task 7. If
   `diagnostics` supplied, require its `reduced_to_original` to match; else raise
   (fit/diagnostic mask mismatch).
2. Reduce `H = H_tilde[:, kept]`, `prior = c0[kept]` (default 0). Run FISTA.
3. Restore full `c_hat` with exact zeros on masked columns; `c_reduced` on kept.
4. `fitted_sensor_vector = H @ c_reduced`, `residual_vector = Y_tilde - fitted`,
   `residual_norm`, `zero_model_residual_norm = ||Y_tilde||`.
5. Reconstruct `theta[T,K] = Phi @ C^T` from `temporal_basis` when provided
   (`C[k,b] = c_hat[col]`); `source_names` in source-index order.
6. `source_contribution_summaries`: total contribution per source (from theta,
   else coefficient sums); when timestamps+theta present, diurnal/hourly mean
   (traffic), daily totals (industry day-to-day), and active-period fraction
   (brick-kiln intermittency). `summarize_report_groups(result, groups)` sums
   member trajectories/contributions for merge recommendations (Task 9 consumes).
7. Active-set covariance: `A_c = {j: c_j > active_tolerance}`,
   `sigma_hat^2 = ||r||^2 / max(N - r_eff(tau_sigma), 1)`,
   `Cov = sigma_hat^2 (H_{A_c}^T H_{A_c} + lam I)^{-1}` (pinv); per-coefficient
   std from the diagonal, mapped to original indices. `r_eff` from
   `svdvals(H) > tau` (tau = tau_sigma or `max(N,J) eps sigma_1`).
8. Warnings: ill-conditioning (numerical rank `< J` or `kappa >
   condition_warning_ratio`), non-convergence.

### Result dataclass `FitResult` (torch-native)
`c_hat`, `c_reduced`, `reduced_to_original`, `original_to_reduced`, `theta`,
`source_names`, `source_contribution_summaries`, `fitted_sensor_vector`,
`residual_vector`, `residual_norm`, `zero_model_residual_norm`,
`source_basis_metadata (column_index)`, `active_indices`, `active_covariance`,
`coefficient_std`, `objective_summary` (initial/final/zero_model),
`convergence_status`, `iteration_count`, `restart_count`, `kkt_residual`,
`solver` (method/sigma_1/L/step), `ensemble_kind`, `warnings`, `config`,
`metadata` (device/dtype/provenance/N/J/J_full). `to_json_summary()` (tensors ->
lists via `to_numpy`, NaN -> None).

### Residual model-adequacy (refitted parametric bootstrap)
`NoiseModel(covariance=None, calibrated=False, source=None,
estimated_from_fit_residual=False)`;
`AdequacyConfig(alpha=0.05, n_replicates=1000, seed=0)`;
`residual_adequacy_check(fit_result, projection_result, noise_model, *,
config=None) -> AdequacyResult`.
- `calibration_status="calibrated"` only if `covariance` present, `calibrated`
  and `source` set, not `estimated_from_fit_residual`, and `bar_Sigma` positive
  definite. Otherwise `uncalibrated`: return raw/projected residual norms and
  sensor-wise, time-wise, and autocorrelation summaries; null test fields; **no
  pass/fail**.
- Calibrated path: `Z` = orthonormal complement of `U_r`
  (`P_Q^perp = Z Z^T`, `[N, N-r]`); `bar_r = Z^T (Y - H_lag c_hat)`,
  `bar_Sigma = Z^T Sigma_e Z`, `T_res = bar_r^T bar_Sigma^{-1} bar_r`.
  Simulate `B_res` sets `Y_b = (H_lag c_hat + U_r U_r^T (Y - H_lag c_hat)) + e_b`,
  `e_b ~ N(0, Sigma_e)` (Cholesky), **refit each replicate with the same FISTA
  (batched on device)**, `T_b = bar_r_b^T bar_Sigma^{-1} bar_r_b`. Flag
  inadequate when `T_res` exceeds the empirical `(1-alpha)` quantile; add-one
  MC `p_value = (1 + #{T_b >= T_res}) / (B_res + 1)`.
- Return `calibration_status, T_res, bootstrap_quantile, p_value, alpha,
  n_replicates, inadequate, noise_model_provenance`, raw/projected norms, and
  the residual summaries.

### Ensemble products (provenance-gated)
- `aggregate_transport_ensemble(results, quantiles=(0.05,0.5,0.95))`: require
  every `ensemble_kind == "transport"`; empirical per-coefficient / per-source
  quantile intervals.
- `aggregate_inventory_scenarios(results)`: require every

## Sanity Gate S4 (`scripts/run_iasa_sanity.py --gate fit`)
Deterministic (fixed seeds). Cases:
- `noiseless`: well-conditioned `H_tilde` (near-orthogonal 3 cols),
  `Y = H c_true`, `c_true = [1.5, 0.7, 0.0]` -> relative coefficient error
  `<= 1e-4`, `min(c_hat) >= -1e-8`, final KKT `<= tol_kkt`.
- `noisy`: small Gaussian noise -> relative error `<= 0.1` and
  `residual_norm < zero_model_residual_norm`.
- `duplicate`: two identical columns -> individual split may be unstable but
  `|(c0 + c1) - true_pair_sum| <= 1e-4` in the noiseless case.
- `ill_conditioned`: near-duplicate columns -> `warnings` contains an
  ill-conditioning flag; result not presented as fully stable.
- `mask`: `fixed_zero_indices` restores exact declared zeros; a fitted near-zero
  *unmasked* coefficient does not trigger post-hoc column removal (mask
  unchanged, column stays fitted).
- `uncalibrated`: adequacy with no noise model -> `calibration_status=
  uncalibrated`, null test fields, summaries present, no pass/fail.
- `calibrated_detects_omission` (small `n_replicates`, seeded): correctly
  specified fit yields finite `T_res`, quantile, `p_value in (0,1]`; injecting a
  residual-visible omitted signal strictly increases `T_res`.
Emit JSON summary; wire `--gate fit` into CLI and `--gate all`.

## Risks
- KKT tolerance must be reachable in the noiseless case; verify on GPU and adjust
  `max_iters` rather than weakening tolerances.
- Batched-bootstrap FISTA per-column monotone restart must be masked correctly so
  one replicate's restart does not perturb others.
- `bar_Sigma` PD check gates the calibrated path; a non-PD or fit-derived
  covariance must fall through to `uncalibrated`.
- Ensemble aggregation must hard-reject mixed provenance, not silently coerce.
