## Core mathematical updates

1. **Replace the constant-only source model with the implemented temporal-basis model.**

   Add
   \[
   \theta_k(t)=\sum_{b=1}^{B}c_{kb}\phi_b(t),\qquad \theta_k(t)\ge0,
   \]
   and define \(H_{\mathrm{lag}}\in\mathbb R^{mT\times KB}\), with source-major, basis-minor columns. The existing \(mT\times K\) formulation becomes the \(B=1\) special case. Update the setup, method, theory, algorithm, evaluation, abstract, and conclusion. [current paper](/scratch/ab9738/stamp/paper/3.setup.tex:471) [implementation](/scratch/ab9738/stamp/model/iasa/response.py:283)

2. **Distinguish coefficient-level from source-level identifiability.**

   Full rank \(K\) currently means source-level identifiability. Under temporal bases, coefficient identifiability requires rank \(KB\). Define how coefficient diagnostics become source-level activity and contribution summaries; do not call individual `(source, basis)` columns “sources.”

3. **Correct the singular-value definitions.**

   The primary score must be the smallest singular value, including zero for deficient matrices—not the smallest nonzero singular value. Condition number must be infinite for rank deficiency. Separate:

   - numerical rank tolerance;
   - noise-dependent effective-rank threshold \(\tau_\sigma\);
   - visibility threshold \(\tau_v\);
   - coherence threshold \(\tau_\rho\).

4. **Define zero/weak-column behavior.**

   Coherence and ray distance are undefined for zero-norm fingerprints. Specify weak-column flags, exclusion from maximum-coherence summaries, and JSON-safe sentinel behavior.

5. **Resolve ray distance.**

   Projected fingerprints are generally signed, so the roadmap’s “nonnegative fingerprints” language is wrong. Either remove ray distance or activate the currently commented signed definition
   \[
   d^{\mathrm{ray}}_{ij}=\sqrt{1-\rho_{ij}^2}.
   \]
   It is presently listed in evaluation but absent from the active theory and compiled PDF. [commented definition](/scratch/ab9738/stamp/paper/5.theory.tex:336)

## Response construction

22. **Extend the response equation to temporal bases.**

    Define each `(source, basis)` fingerprint as releases weighted by \(\phi_b(\tau)\), with constant activity as a special basis.

23. **Document direct sensor evaluation.**

    The implementation evaluates the Gaussian kernel directly at sensor coordinates; grid quadrature is used separately for retained-mass diagnostics. The current grid-response equation with \(\Delta V_g\) does not describe the implemented \(H_{\mathrm{lag}}\) calculation exactly. [paper](/scratch/ab9738/stamp/paper/4.method.tex:662) [code](/scratch/ab9738/stamp/model/iasa/response.py:221)

24. **Add exact puff semantics.**

    Include integer cell centers, physical extents \([-0.5,N_x-0.5]\times[-0.5,N_y-0.5]\), Euler substeps with a fractional final step, same-time releases, minimum dispersion age, mean-wind orientation, zero-wind fallback, finite lag, and whole-puff removal after center exit.

25. **Clarify mass accounting.**

    Retained/dropped mass is measured per release kernel using quadrature and must not be inferred by summing repeated sensor observations. Separate kernel boundary/truncation loss from release exit loss.

26. **Qualify “differentiable.”**

    The mathematical puff model is differentiable, but the completed response builder is NumPy-based and not an automatic-differentiation path. Do not imply that the implemented response currently supports end-to-end gradient refinement.

27. **Define baseline and initial-condition handling.**

    Task 5 currently uses an all-zero source baseline. The paper separately describes kriged initial conditions. State whether kriging is limited to auxiliary PDE experiments or how its zero-source trajectory is removed before applying the puff response.

28. **Separate the two forward models.**

    The existing PDE utility uses edge-hold boundaries; paper-facing \(H_{\mathrm{lag}}\) uses the open-boundary Gaussian puff operator. Explain which generates synthetic observations and which is used for inference, especially in response-error experiments.
