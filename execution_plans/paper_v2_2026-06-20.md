### Task 8: PyTorch nonnegative fitting and uncertainty

Use projected FISTA as the primary solver for

\[
\min_{\mathbf c\ge0}
\|\widetilde Y-\widetilde H_\Phi\mathbf c\|_2^2
+\lambda\|\mathbf c-\mathbf c_0\|_2^2.
\]

Solver contract:

- Compute a valid Lipschitz step from the largest singular value or a recorded
  power-iteration estimate.
- Project with `torch.clamp(c, min=0)` so inactive coefficients can be exactly
  zero.
- Use monotone restart when acceleration raises the objective.
- Stop using projected-gradient/KKT residual plus relative objective change and
  a configured iteration cap.
- Return coefficients, reconstructed activities, fitted/raw projected
  trajectories, residuals, objective history summary, iteration count,
  convergence status, KKT residual, device, and dtype.
- Compute active-set covariance with `torch.linalg` on
  \(\widetilde H_{\Phi,\mathcal A}^\top
  \widetilde H_{\Phi,\mathcal A}+\lambda I\).
- Batch wind-ensemble and bootstrap refits on GPU when shapes permit.
- No SciPy fallback or hidden CPU solver is allowed.
