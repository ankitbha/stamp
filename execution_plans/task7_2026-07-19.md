# Task 7 Execution Plan: Identifiability diagnostics

## Objective

Compute coefficient-level identifiability diagnostics for the projected
source--basis response `H_tilde` (Task 6), map them to source-level warnings, and
provide an empirical wind-distribution summary. PyTorch-native, on the input
device/dtype; NumPy only at serialization. No tangent-cone / fitted-active-set
path — guarantees are uniform over the predeclared admissible column set.

## Context (verified)

- Task 6 `ProjectionResult` provides torch tensors `H_tilde`, `H_removed`
  (= `P_Q H_lag`), with `H_tilde + H_removed == H_lag`, plus `column_index`
  (source-major/basis-minor: `source_index, source_name, basis_index, basis_name`)
  and device/dtype provenance. Task 6A made all of this torch on-device.
- Paper `5.theory.tex` defines every quantity: padded `sigma_J`, `tau_num`,
  `r_num`, `kappa`, `tau_sigma`/`r_eff`, visibility `v_j`, weak set `W`,
  coherence `rho_ij`, ray distance `sqrt(1-rho^2)`, absorption `a_j`, ambiguity
  set `A`, and the source ambiguity graph (graph/components are Task 9; Task 7
  produces pairs + cross-source summaries).

## Design — new `model/iasa/diagnostics.py`

### Config
`DiagnosticsConfig(fixed_zero_indices=(), tau_sigma=None, tau_v=0.0,
tau_rho=0.99)`.
- `fixed_zero_indices`: original-space column indices removed before diagnosis.
- `tau_sigma`: noise-dependent effective-rank threshold; `None` -> use `tau_num`
  (so `r_eff == r_num`) and record `noise_threshold_provided=False`.
- `tau_v`: visibility weak threshold `W = {j: v_j <= tau_v}`.
- `tau_rho`: ambiguity coherence threshold (default 0.99, conservative near 1).

### Core
`diagnose_identifiability(H_tilde, column_index, *, H_removed=None, H_lag=None,
config=None) -> DiagnosticsResult`, plus convenience
`diagnose_projection(projection_result, config=None)` that pulls `H_tilde`,
`H_removed`, and `H_lag = H_tilde + H_removed` from a `ProjectionResult`.

Steps (torch on `H_tilde.device`/dtype):
1. Validate `fixed_zero_indices` against `len(column_index)`; build
   `reduced_to_original` (sorted kept indices) and `original_to_reduced`
   (orig->reduced or -1). Reduced `Ht = H_tilde[:, kept]`, `J = len(kept)`,
   `N = Ht.shape[0]`.
2. Gram `G = Ht.T @ Ht` (`[J,J]`). `torch.linalg.eigvalsh(G)` gives exactly `J`
   eigenvalues (natural zero-padding when `J>N`/deficient).
   `sigma = sqrt(clamp(eig, min=0))`, sort descending. `sigma_1=sigma[0]`,
   `sigma_J=sigma[-1]` (padded min = identifiability score).
3. `tau_num = max(N,J)*eps(dtype)*sigma_1`; `r_num = count(sigma > tau_num)`.
4. `kappa = sigma_1/sigma_J` if `r_num==J` else inf; `condition_status`
   `finite`/`infinite`; JSON-safe value (`None` for inf).
5. `tau_sigma_eff = tau_sigma if given else tau_num`;
   `r_eff = count(sigma > tau_sigma_eff)`.
6. Visibility `v = sqrt(clamp(diag(G), min=0))`; `weak = v <= tau_v`.
7. Coherence `rho_ij = |G_ij| / (v_i v_j)` for eligible pairs (`v_i,v_j>0` and
   not weak); ineligible -> NaN sentinel in tensor, `null` in JSON; clamp `[0,1]`.
   Ray distance `sqrt(clamp(1-rho^2, min=0))`, same eligibility.
8. Absorption: if `H_lag`/`H_removed` available, `a_j = ||H_removed_j|| /
   ||H_lag_j||` where `||H_lag_j|| > tol`, else `null`. No `H_lag` -> all `null`.
9. Ambiguity pairs `A = {(i,j) eligible, i<j, rho_ij > tau_rho}` with recorded
   coherence, ray distance, and source/basis metadata for each endpoint.
10. Cross-source summary: among eligible pairs with different sources, record the
    max-coherence pair and min-ray-distance pair (exact `(i,j)` + metadata).
    Per-source weak-basis flags.
11. Perturbation sensitivity: `1/sigma_J` (inf if `sigma_J==0`) and `kappa`, each
    with explicit status + JSON-safe value.
12. Provenance: `runtime_provenance(device,dtype)`, `tau_*`, mappings, reduced
    `column_index`, warnings.

### Result dataclass `DiagnosticsResult` (torch-native)
`singular_values` (tensor `[J]`), `sigma_1/sigma_J/sigma_min_positive`,
`numerical_rank/numerical_tolerance`, `condition_number/condition_status`,
`effective_rank/effective_rank_threshold/noise_threshold_provided`,
`visibility` (tensor), `weak_flags`/`weak_set`, `coherence`/`ray_distance`
(tensors with NaN sentinels), `background_absorption`, `ambiguous_pairs`,
`cross_source_max_coherence`, `cross_source_min_ray_distance`, `per_source_weak`,
`perturbation_sensitivity`, `original_to_reduced`, `reduced_to_original`,
`column_index`, `config`, `metadata`. Methods `to_json_summary()` (NaN->None,
tensors->lists via `to_numpy`) and `human_readable_table()`.

### Wind-ensemble aggregation
`summarize_wind_ensemble(results, *, quantiles=(0.05,0.5,0.95), window_ids=None)`:
5/50/95 percentiles of `sigma_J`; P(full numerical rank), P(full effective rank);
per-coefficient weak probabilities; per-source-pair ambiguity probabilities;
frequencies of conservative report components (local union-find over ambiguous
source pairs per window — Task 9 formalizes). Deterministic; requires identical
`column_index`/mappings across windows.

## Sanity Gate S3 (`scripts/run_iasa_sanity.py --gate diagnostics`)
- `orthogonal_case`: synthetic near-orthogonal `H_tilde` -> full rank,
  `max_coherence<=0.1`, finite condition.
- `duplicate_case`: column 2 == column 1 -> rank deficiency, duplicate-pair
  `coherence>=0.999`, `sigma_J==0`, infinite condition.
- `weak_case`: one near-zero column (`~1e-10`), `tau_v=1e-6` -> flagged weak,
  pairwise metrics `null`.
- Matched wind comparison: build real responses (empty background so
  `H_tilde==H_lag`) for a multi-source/basis/sensor geometry under `eastward` vs
  `two_direction` wind with identical columns. Assert
  `two_direction_sigma_J >= eastward_sigma_J - 1e-8` and
  `two_direction_max_coherence <= eastward_max_coherence + 1e-8`. Geometry: two
  compact interior sources offset along x on the same y-line (coherent under pure
  eastward advection); sensors include east and north sensors so the northward
  second phase separates them. Tune on GPU until inequalities hold; redesign,
  never weaken.
- Emit JSON summary; wire `--gate diagnostics` into CLI and `--gate all`.
