# Task 6 Findings Remediation Plan

## Summary

Correct daily harmonic semantics, make tolerance-based column classification consistent with effective rank, and support zero-row background matrices without crashes. Preserve all public APIs and existing Gate S1/S2 behavior.

## Implementation Steps

1. **Separate elapsed time from time-of-day**
   - In `model/iasa/background.py`, retain elapsed hours from the first timestamp for temporal polynomial columns.
   - Independently calculate fractional hours since each timestamp’s calendar-day boundary.
   - Build daily sine/cosine harmonics from hours since midnight, including fractional hours.
   - Record in metadata that temporal polynomials use elapsed time while harmonics use clock time.
   - Preserve existing results for midnight-starting Gate S2 timestamps.

2. **Handle zero-row matrices safely**
   - Update background rank calculation to treat any matrix with `min(Q.shape) == 0` as rank zero, with no singular values and tolerance zero.
   - Apply the same handling in `fit_background_projector`, producing `U_r` with shape `[row_count, 0]`.
   - Ensure a default constant configuration with an empty `row_index` returns `Q.shape == (0, 1)` and effective rank zero.
   - Confirm empty projections return correctly shaped arrays and JSON-safe metadata.

3. **Correct independent/dependent column classification**
   - In `model/iasa/projection.py`, calculate numerical rank for every complete left-to-right prefix `Q[:, :i+1]` using the fitted projector’s exact tolerance.
   - Mark the current column independent only when its prefix increases rank; otherwise mark it dependent.
   - Verify the number of independent names equals the projector’s effective rank.
   - Preserve existing behavior for ordinary independent columns and exact duplicates.

4. **Expand regression tests**
   - Add a non-midnight harmonic test: at 06:00, the first harmonic must produce sine `1` and cosine `0`.
   - Add a midnight-crossing test to verify clock-time phase continuity.
   - Add an explicit-tolerance case where two individually sub-threshold duplicate columns jointly raise prefix rank; require metadata to report one independent column and effective rank one.
   - Add zero-row tests for constant, empty, and projected bases, including shapes, rank, singular values, tolerance, and JSON serialization.
   - Keep existing exact-value, redundancy, projection, and Gate S2 assertions unchanged.

5. **Run acceptance checks**
   - Run `git diff --check` and syntax compilation.
   - Run all repository tests.
   - Run response, projection, and all sanity gates.
   - Run `scripts/smoke_iasa_runtime.py` in the supported container.
   - Confirm Gate S2 remains rank four with unchanged visibility and absorption thresholds.

## Public APIs

No signatures or exported symbols change. Only background column values for non-midnight timestamps, tolerance-derived metadata, and zero-row behavior are corrected.

## Assumptions

- Input timestamps represent the intended local clock used for time-of-day effects; no timezone conversion is introduced.
- Empty row indices remain valid and produce rank-zero matrices rather than being rejected.
- “Left-to-right rank increase” means numerical rank of each complete input prefix under the projector’s recorded absolute tolerance.
