# Gate S7 Execution Plan — Adequacy Calibration Study

Date: 2026-07-19
Spec: `ROADMAP_STAMP_NEW.md` "Gate S7 (adequacy calibration study)".

## Objective

S4 confirms the refitted parametric-bootstrap adequacy check on single instances;
S7 confirms it is statistically **calibrated** so the p-values the experiments
report can be trusted. Add `--gate calibration`: under a correctly specified,
externally calibrated noise model, simulate many independent observation sets,
refit each, run the bootstrap adequacy check, and estimate the empirical rejection
rate and p-value distribution; then confirm power rises with omitted-signal
amplitude.

## Design

Synthetic, deterministic, fast (the study is a statistical property of the check,
so a clean well-conditioned operator is preferable to a heavy real response; the
with-background path is already covered by Gate S6).

- Operator `H`: `N=48` rows, 4 source columns (single "constant" basis). Built
  deterministically as `qr(randn(48,4, seed))` orthonormal columns scaled by
  distinct factors -> well-conditioned AND the columns are mutually orthogonal, so
  the omitted column's signal lands entirely in the residual (clean power).
- Fit sources = columns 0,1,2; column 3 is the **omitted** source, fixed to zero
  in the fit (`FitConfig(fixed_zero_indices=(3,))`). Empty background
  (`include_constant=False`) so `U_r` has 0 columns (the adequacy no-background
  branch, already bug-fixed in Task 8).
- Correctly specified null = omitted amplitude `a=0` (truth column 3 = 0, fit spans
  the truth mean). Misspecified = `a>0` (omitted signal of increasing amplitude).
- Noise: `Y = H c_true + sigma_e * z`, `z ~ N(0, I_N)`, `sigma_e` known. The
  supplied `NoiseModel(covariance=sigma_e^2, calibrated=True, source=...,
  estimated_from_fit_residual=False)` is correctly specified (same `sigma_e`).
- Amplitudes `(0.0, 0.1, 0.2, 0.35, 0.6, 0.8)` chosen so power ramps from ~alpha to
  ~1 (noncentrality `lambda = (a*||h_omit||/sigma_e)^2`). Adjusting amplitudes to
  span the power curve is design, NOT tuning the uniformity pass threshold.
- Per trial: `project_response_and_observations` -> `fit_projection(config)` ->
  `residual_adequacy_check(alpha, n_replicates, seed)`. Record `inadequate` and
  `p_value`. Distinct deterministic seed per (amplitude, trial) and per bootstrap.

Defaults: `n_trials=200`, `n_replicates=100`, `alpha=0.05`, `seed=0`.

## Checks (roadmap tolerances)

1. `correctly_specified_rejection_rate` within `alpha +/- 2*sqrt(alpha(1-alpha)/n_trials)`.
2. Null p-values approximately uniform: one-sample KS statistic vs U[0,1]
   `<= uniformity_threshold` (0.15, generous for discreteness + MC; reported with
   p-value quantiles, not tuned).
3. `power_increases_monotonically_with_omission_amplitude`: rejection rates
   non-decreasing across amplitudes (small MC slack) and the largest amplitude
   reaches high power (`>= 0.9`).
4. Deterministic under fixed seed: re-running one trial's adequacy with the same
   seed reproduces `T_res`/`p_value` exactly. Record `n_trials`, `alpha`,
   `n_replicates`, and noise-model provenance.
