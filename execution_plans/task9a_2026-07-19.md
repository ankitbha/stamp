# Task 9A Execution Plan: Gridded FieldFormer wind field and transport ensembles

## Objective

Upgrade the New Delhi wind input from the v1 city-level `WindSequence` to a
paper-facing **gridded** wind field `W_hat in R^{T x n x 2}` produced by a
coordinate-query imputer queried on every response-grid cell and hour, and add
**transport wind-field ensembles**. The gridded field must drive the existing
Task 5 response builder through the `WindSampler.sample(t, position_xy)` interface
with no change to response/diagnostics/fitting signatures, and ensemble members
must be tagged `ensemble_kind="transport"` and never pooled with inventory
scenarios.

## Context (verified against paper/4.method.tex subsec:wind_field_estimation)

- Transport-vector convention (eq. wind_direction_conversion):
  `Ux = -WS*sin(WD*pi/180)`, `Vy = -WS*cos(WD*pi/180)` (WD meteorological
  "from"; transport points where pollution moves).
- FieldFormer is a coordinate-query model
  `w_hat_t(x_g) = f_omega(x_g, t; {(z_i,t',u_i,m_i)})` (eq. fieldformer_wind_field);
  queried on every grid cell -> `W_hat in R^{T x n x 2}`.
- Grid-displacement conversion (eq. wind_unit_conversion):
  `vx_grid = Ux*dt_s/dx_m`, `vy_grid = Vy*dt_s/dy_m`; artifacts record scales,
  convention, units, and the exact converted sequence.
- Ensembles `{w_hat^(r)}` from held-out-calibrated error, station bootstrap,
  checkpoint ensembles, or validation-residual-matched perturbations; each queried
  on the same grid, converted to displacement, tagged transport, kept separate
  from inventory scenarios. Real-data validation masks stations and measures
  held-out station-time error; no dense city-wide truth is assumed.

Existing interfaces (verified): `WindSampler` Protocol (`provider`, `metadata`,
`sample(t_index, position_xy)->[vx,vy]`) and `CityWindSampler` (ignores position)
in `response.py`; `build_lagged_response_matrix` accepts any object with
`.sample` via `_as_wind_sampler`. `wind.py` is an ingestion-boundary module
(numpy/pandas allowed). FieldFormer itself is not vendored here, so the default
imputer is a kernel coordinate-query model satisfying the same `f_omega` contract;
a FieldFormer adapter can be substituted through the same protocol.

## Design

### `model/iasa/wind.py` additions (numpy ingestion boundary)
- `transport_vectors_from_wd_ws(wd_deg, ws) -> [...,2]` applying
  eq. wind_direction_conversion.
- `CoordinateQueryImputer` Protocol: `name`, `query(coords_xy[n,2], t_index,
  station_coords, station_vectors, station_mask) -> [n,2]`.
- `KernelCoordinateQueryImputer(length_scale, min_active)`: per hour, normalized
  Gaussian-kernel interpolation from observed station vectors to query coords
  (a genuine coordinate-query field, not city-averaged). Falls back to the
  observed-station mean for a query far from all stations; raises if an hour has
  no observed station.
- `GriddedWindField` dataclass: `field` (grid-displacement `[T, Nx, Ny, 2]`),
  `physical_field` (`[T, Nx, Ny, 2]`), `grid_shape`, `timestamps`,
  `station_coords`, `station_vectors`, `station_mask`, `dt_s`, `dx_m`, `dy_m`,
  `convention`, `provider`, `ensemble_kind`, `metadata` (imputer name, seed,
  held-out split, device/dtype note, units).
- `build_gridded_wind_field(station_coords, station_vectors, station_mask,
  timestamps, grid_shape, *, imputer=None, dt_s, dx_m, dy_m, seed=0,
  provider=..., ensemble_kind="transport", extra_metadata=None)`: query the
  imputer on all `Nx*Ny` cell centers (x-major) per hour -> physical `[T,n,2]`,
  reshape to `[T,Nx,Ny,2]`, convert to grid displacement, validate finite.
- `evaluate_gridded_wind_heldout(station_coords, station_vectors, station_mask,
  timestamps, *, imputer, holdout_station_indices)`: mask held-out stations from
  the imputer inputs, predict at their coords, and report vector RMSE, mean
  direction error (deg), and mean speed error over held-out observed
  station-times.
- `build_wind_field_ensemble(..., n_members, method, seed)`: `method` in
  {`station_bootstrap`, `residual_perturbation`}; return a list of
  `GriddedWindField` each tagged `ensemble_kind="transport"` with a member seed.
- `gridded_new_delhi_wind_field(...)`: real-data convenience (load stations, map
  lon/lat to grid, convert, build field); keeps v1 city-level provider available
  under its existing label for smoke checks.

### `model/iasa/response.py` (sampler adapter only)
- `GriddedWindSampler` (frozen dataclass) implementing `WindSampler`:
  `field[T,Nx,Ny,2]`, `provider`, `metadata`, temporal `interpolation`.
  `sample(t_index, position_xy)`: bilinear spatial interpolation over grid cells
  (clamped to `[0,Nx-1]x[0,Ny-1]`) + linear temporal interpolation; returns
  `[vx,vy]` grid displacement. Classmethod `from_gridded_wind_field(field,
  interpolation="linear")`. Add to `__all__`.

### Exports
`model/iasa/__init__.py`: `GriddedWindField`, `GriddedWindSampler`,
`CoordinateQueryImputer`, `KernelCoordinateQueryImputer`,
`transport_vectors_from_wd_ws`, `build_gridded_wind_field`,
`build_wind_field_ensemble`, `evaluate_gridded_wind_heldout`,
`gridded_new_delhi_wind_field`.

## Sanity Gate (`scripts/run_iasa_sanity.py --gate wind_field`)
Synthetic stations (deterministic), grid `Nx=Ny=16`, `T` short:
- Transport-vector convention: WD=0 -> (0,-WS); WD=90 -> (-WS,0); WD=270 ->
  (+WS,0).
- Gridded field shape `[T,16,16,2]` aligned to the response grid.
- A spatially varying station field yields a spatially varying gridded field
  (cell-to-cell variation above tolerance) -- not city-averaged.
- The `GriddedWindSampler` drives `build_lagged_response_matrix` unchanged and
  produces a finite nonzero `H_lag`; the sampler recovers station vectors near
  station cells within tolerance.
- Held-out validation returns finite vector/direction/speed error over a masked
  split.
- An `R`-member transport ensemble: every member tagged `transport`; members
  differ; `aggregate_transport_ensemble` over fits from the members yields
  intervals, and mixing a member fit tagged `inventory` is rejected.
Wire `--gate wind_field` into the CLI and `--gate all`.

## Tests -- `tests/test_iasa_wind_field.py`
Conversion identities; field shape/alignment; spatial variation; sampler bilinear
+ temporal interp correctness (constant field -> constant sample; linear ramp ->
linear sample); sampler drives the response builder unchanged; held-out error
finite and lower for a matched imputer than a shuffled baseline; ensemble member
count + transport tagging + member divergence; determinism under fixed seed;
public exports. Pin `torch.set_num_threads(1)`.

## Acceptance mapping
Roadmap Task 9A acceptance checks: field shape `[T,n,2]` aligned to grid;
held-out station-time error over a masked split; gridded field drives
`build_lagged_response_matrix` with no signature change; ensemble members tagged
`transport` and never pooled with inventory. Convention + scales + convention
recorded in the artifact.

## Risks
- Grid indexing must be consistent (x-major cell ordering; sensor/position coords
  in grid units) between `build_gridded_wind_field`, the reshape to
  `[T,Nx,Ny,2]`, and `GriddedWindSampler` bilinear lookup.
- Direction-error metric must handle circular wrap-around (angle difference mod
  360, folded to [0,180]).
- Ensemble members must stay `transport`; reuse `validate_ensemble_kind` and the
  Task 8 pooling guard so inventory mixing is rejected.
- The default kernel imputer is not FieldFormer; label it clearly and keep the
  protocol pluggable so the trained model can replace it without API changes.
