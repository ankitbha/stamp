  Y=H_{\Phi}^{\mathrm{lag}}\mathbf c+Q\boldsymbol\gamma+E,
  \qquad H_{\Phi}^{\mathrm{lag}}\in\mathbb R^{mT\times J}.

## 3. Singular Values, Rank, and Thresholds

In `5.theory.tex`, define \(J\) singular values through \(\widetilde H_\Phi^\top\widetilde H_\Phi\), padding with zeros whenever necessary:

\[
\sigma_1\ge\cdots\ge\sigma_J\ge0.
\]

Define:

- Primary identifiability score:
  \[
  \mathcal I=\sigma_J(\widetilde H_\Phi).
  \]
- Numerical tolerance:
  \[
  \tau_{\mathrm{num}}
  =\max(mT,J)\,\epsilon_{\mathrm{mach}}\,\sigma_1.
  \]
- Numerical rank:
  \[
  r_{\mathrm{num}}=\#\{i:\sigma_i>\tau_{\mathrm{num}}\}.
  \]
- Noise-dependent effective rank:
  \[
  r_{\mathrm{eff}}(\tau_\sigma)
  =\#\{i:\sigma_i>\tau_\sigma\},
  \]
  where \(\tau_\sigma\) is recorded separately and is not reused as the numerical SVD tolerance.
- Condition number:
  \[
  \kappa=
  \begin{cases}
  \sigma_1/\sigma_J,&r_{\mathrm{num}}=J,\\
  \infty,&r_{\mathrm{num}}<J.
  \end{cases}
  \]

If useful, retain the smallest numerically positive singular value under the distinct name \(\sigma_{\min,+}\), but explicitly state that it is not the paper’s identifiability score and cannot make a deficient matrix appear stable.

Update the theorem, diagnostics table, algorithm, H1 evaluation, conclusion, and all prose using “smallest nonzero singular value.”

## 4. Weak and Zero Fingerprints

Introduce thresholds \(\tau_v\ge0\) and \(\tau_\rho\in[0,1]\):

\[
v_j=\|\widetilde{\mathbf h}_j\|_2,\qquad
\mathcal W=\{j:v_j\le\tau_v\}.
\]

Specify:

- A coefficient fingerprint with \(v_j\le\tau_v\) is weakly visible.
- Coherence and ray distance are reported as undefined when either participating fingerprint is weak.
- Undefined entries appear as “N/A” in tables and are excluded from maximum-coherence and minimum-ray-distance summaries.
- Weak coefficients are flagged independently and never treated as safely distinguishable merely because their pairwise metrics are undefined.
- Coherence warnings use only eligible pairs:
  \[
  \mathcal A=\{(i,j):i,j\notin\mathcal W,\ \rho_{ij}>\tau_\rho\}.
  \]

Add these conventions to the active theory, algorithm flagging step, reporting protocol, evaluation metrics, and diagnostics table.

## 5. Reactivate Ray Distance

In `5.theory.tex`:

- Take the existing commented ray-distance block and reactivate it immediately after the active coherence definition; do not revive the surrounding obsolete draft.
- Reuse the existing labels `eq:ray_distance` and `eq:ray_distance_coherence_relation`, ensuring no second active copy exists.
- Define ray distance for eligible signed projected fingerprints:
  \[
  d^{\mathrm{ray}}_{ij}
  =
  \min_{c\in\mathbb R}
  \frac{\|\widetilde{\mathbf h}_i-c\widetilde{\mathbf h}_j\|_2}
       {\|\widetilde{\mathbf h}_i\|_2}
  =
  \sqrt{1-\rho_{ij}^2}.
  \]
- Use
  \[
  \sqrt{\max(0,1-\rho_{ij}^2)}
  \]
  in implementation-oriented prose to guard against floating-point overshoot.
- Explain that this is an unoriented linear-ray diagnostic for signed projected fingerprints; it is not based on nonnegative projected vectors.
- State that high coherence and small ray distance encode the same pairwise geometry, so ray distance is complementary reporting rather than an independent identifiability theorem.

Add ray distance to:

- the active diagnostics table;
- the algorithm’s audit and reporting steps;
- evaluation metric definitions;
- ambiguous-pair tables;
- the conclusion’s list of reported diagnostics.
