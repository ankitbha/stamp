## Findings

- **P1 — Diagnostic unit is undefined.** The paper assumes one column per source, \(\widetilde H\in\mathbb R^{mT\times K}\), while Task 5 produces source × temporal-basis columns. Task 7 must explicitly choose coefficient-level diagnostics or define a paper-consistent source aggregation. [roadmap](/scratch/ab9738/stamp/ROADMAP_STAMP_NEW.md:903) [paper](/scratch/ab9738/stamp/paper/3.setup.tex:563)

- **P1 — “Smallest nonzero singular value” conflicts with the paper.** The paper’s primary score is the smallest singular value, which must be zero for rank-deficient matrices; condition number should then be infinite. Reporting the smallest nonzero value would make the duplicate case look artificially stable. Numerical rank tolerance and noise-dependent effective-rank threshold \(\tau_\sigma\) also need separate definitions. [roadmap](/scratch/ab9738/stamp/ROADMAP_STAMP_NEW.md:914) [paper](/scratch/ab9738/stamp/paper/5.theory.tex:660)

- **P1 — Gate S3’s wind comparison lacks comparable multi-source matrices.** Gate S1’s current eastward/two-direction pair contains only one source column, so coherence and separability cannot be tested. S3 should build identical multi-source column sets under both wind regimes. [roadmap](/scratch/ab9738/stamp/ROADMAP_STAMP_NEW.md:959) [sanity runner](/scratch/ab9738/stamp/scripts/run_iasa_sanity.py:341)

- **P2 — Threshold and zero-column behavior is underspecified.** The paper requires \(\tau_\sigma\), \(\tau_\rho\), and \(\tau_v\). The roadmap requests warning flags without defining these thresholds or how coherence handles zero-norm columns. [paper](/scratch/ab9738/stamp/paper/6.algorithm.tex:416)

- **P2 — Ray distance is inconsistent.** Projected fingerprints can be signed, so “nonnegative source fingerprints” is incorrect. Moreover, ray distance appears in the evaluation metrics but its theory equation is commented out and absent from the compiled PDF. Either remove it from Task 7 or define it for signed nonzero fingerprints as \(\sqrt{1-\rho_{ij}^2}\). [roadmap](/scratch/ab9738/stamp/ROADMAP_STAMP_NEW.md:934) [commented definition](/scratch/ab9738/stamp/paper/5.theory.tex:336)

- **P2 — Paper-defined quantities should not be loosened.** Background absorption should specifically be the removed/raw norm ratio \(a_k\), not an ambiguously named complement. Perturbation “proxies” should be explicitly named \(1/\sigma_{\min}\) and \(\kappa\); the actual paper bound additionally requires \(\delta_H\), noise, and coefficient magnitude. [paper](/scratch/ab9738/stamp/paper/5.theory.tex:700)

The core metric list otherwise matches the paper, but Task 7 is not yet decision-complete for implementation.
